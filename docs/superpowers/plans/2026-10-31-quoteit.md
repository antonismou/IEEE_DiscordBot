# /quoteit and /randomquote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Members turn any message into a random, chaotic animated meme GIF (`/quoteit`, right-click "Quote it") and re-roll saved quotes (`/randomquote`).

**Architecture:** A new `bot/quotes/` package holds pure, testable pieces (repo, background sourcing, renderer); `bot/cogs/quotes.py` wires them to Discord. Blocking work (HTTP, Pillow) runs in `asyncio.to_thread`. Background order: Giphy, then a local meme folder, then a procedurally generated background, so a render never fails for lack of a source.

**Tech Stack:** Python 3.12, discord.py 2.7, Pillow, requests, SQLite (existing).

**Spec:** `docs/superpowers/specs/2026-10-31-quoteit-design.md`

## Global Constraints

- Any member may use both commands: no verification, officer or role check.
- Giphy rating filter: `pg-13`. Key from env `GIPHY_API_KEY`, optional; at most one Giphy search per command.
- Output is an animated GIF, at most `MAX_GIF_BYTES = 8_000_000` bytes (Discord upload limit).
- Rendering and HTTP never run on the event loop (`asyncio.to_thread`).
- Quote text is trimmed to 280 characters with a trailing `…`.
- Refusals (ephemeral, friendly): bot author, empty text (attachment-only), message not found/unreadable.
- Per-user cooldown 15 s, implemented in the cog (not `app_commands.checks.cooldown`: `handle_app_command_error` would show "Only branch officers" for any `CheckFailure`).
- Posted with `allowed_mentions=discord.AllowedMentions.none()`; quoted text is never put in message content.
- Bundled font must cover Greek and Latin: `assets/fonts/DejaVuSans-Bold.ttf`.
- Follow repo style: `from __future__ import annotations`, repos take `conn`, tests use `conn` fixture and `tests/fakes.py`.

## Review Focus

- Giphy returns an error, junk bytes or a non-GIF: falls back to local, then procedural; never raises.
- A huge or very long animated background: output still under `MAX_GIF_BYTES`.
- Greek text, a 200-character word with no spaces, and `@everyone`/`<@123>` in the quote: renders, wraps, and pings nobody.
- Target message deleted, in a channel the bot cannot read, or a bad link/ID: friendly refusal, no traceback.
- `/randomquote` with an empty table, and a second command inside the cooldown.

### Task 4: GIF renderer with chaos effects

**Files:**
- Create: `bot/quotes/render.py`
- Test: `tests/test_quote_render.py`

**Interfaces:**
- Consumes: `generated_background(rng) -> bytes` from Task 3 (tests only).
- Produces:
  - `FONT_PATH = Path("assets/fonts/DejaVuSans-Bold.ttf")`, `MAX_GIF_BYTES = 8_000_000`, `MAX_FRAMES = 30`, `MAX_WIDTH = 480`
  - `EFFECTS: dict[str, Callable[[list[Image.Image], random.Random], list[Image.Image]]]` with keys exactly `shake`, `glitch`, `deepfry`, `stickers` (each returns frames of the same count and size)
  - `def pick_effects(rng: random.Random) -> list[str]` (1 to 3 distinct names from `EFFECTS`, plus `"typewriter"` chosen with probability 0.3 independently)
  - `def render_quote_gif(background: bytes, *, text: str, author: str, year: int, rng: random.Random, max_bytes: int = MAX_GIF_BYTES) -> bytes` (decodes at most `MAX_FRAMES` frames resized to at most `MAX_WIDTH` wide; applies the picked effects; draws the wrapped, outlined quote text and a `— {author}, {year}` credit; `typewriter` reveals the text progressively across frames; saves as looping GIF; while the result exceeds `max_bytes`, shrink width by 25% and drop every other frame, until it fits or reaches 120 px wide)
  - `def clip_text(text: str, limit: int = 280) -> str`

- [ ] **Step 1: Write failing tests**: `test_clip_text_trims_with_ellipsis` (281 chars → length 280, ends with `…`; short text unchanged); `test_pick_effects_returns_known_names_and_is_seeded`; `test_each_effect_keeps_frame_count_and_size` (parametrized over `EFFECTS`); `test_render_returns_an_animated_gif` (open result, `is_animated`, `format == "GIF"`); `test_greek_text_renders`; `test_long_unbroken_word_renders` ("a"*200); `test_huge_background_fits_the_byte_cap` (build a 60-frame 1200×900 noisy GIF, `max_bytes=300_000`, assert `len(result) <= 300_000`); `test_static_png_background_renders` (single frame still produces a valid GIF).
- [ ] **Step 2:** Run `pytest tests/test_quote_render.py -v`; expect FAIL (import error).
- [ ] **Step 3:** Implement with Pillow only (`ImageSequence`, `ImageDraw`, `ImageFont.truetype(FONT_PATH, size)`, `ImageEnhance`, `ImageFilter`). Font size scales with image width; wrap by measured width and hard-break words wider than the image; outline text via `stroke_width`. Stickers are drawn shapes/emoji-free glyphs from the bundled font (e.g. "💀" is not in the font, so use "!?", "LOL", stars), placed with `rng`.
- [ ] **Step 4:** Run the file; expect PASS. Then run once and write a sample to `/tmp`-free scratchpad path to eyeball: `python -c` writing `sample.gif` into the session scratchpad and open it.
